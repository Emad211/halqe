# Halqe

این مخزن خانهٔ نسخهٔ جدید پروژهٔ «حلقه» است.

در مرحلهٔ نخست، نرم‌افزار حسابداری موجود از مخزن `Emad211/clinic_managment` به پوشهٔ `accounting/` منتقل می‌شود. دادهٔ عملیاتی، دیتابیس واقعی، خروجی‌های build و فایل‌های محیطی وارد این مخزن نمی‌شوند.

## ساختار اولیه

- `accounting/` — برنامهٔ حسابداری فعلی کلینیک (Flask + SQLite)
- اجزای جدید حلقه و پل فقط‌خواندنی در مراحل بعدی کنار این بخش ساخته می‌شوند.
